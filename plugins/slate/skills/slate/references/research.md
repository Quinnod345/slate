# Research: sources you can cite later

Slate's craft rules came from research that cited its sources, and the rules held because the sources could be
re-checked. Do research the same way.

## Reading the web

- Read pages with fetch and search tools. Never open a web browser. When a page must be driven (a login, a script that
  only renders in a browser, a capture), use Aside.
- Read vendor documentation as its official Markdown when the vendor offers it (a docs site's `llms.txt` usually says
  how: often the page path plus `.md`), so quotes are verbatim.
- Keep a dated source list with every research note: title, URL, when you read it, and a short label to cite it by.
- Quote sparingly and exactly; paraphrase the rest in your own words.

## Checking claims about tools and models

- Check the best current models against the live API (its models list or schema) at the start of a project; model
  catalogues and prices move weekly.
- Check that a tool's repository exists and does what the listing claims before recommending it (dependencies.md).
- Re-check a vendor catalogue before assuming a gap still exists (a model family that was missing last month may be
  there now).
- Measure before trusting a new metric: check it against the owner's ear or eye on takes they've already judged.

## Research that feeds a film

- **Truth research** (claims, the product's real screens, numbers and words) lives in the film's truth pack and cites
  a pinned source for everything (slate-story).
- **Reference films** are analyzed with `slate analyze <video>`: a method table, what ran, what came out, so the results
  can be re-derived (slate-brand).
- **Motion and voice research** (how good marks move, how a voice should sound) produces a sourced spec or brief, cited
  by label; the sources stay with it.

## When research is the wrong move

Research fixes a specific, named flaw. It is never a way to redesign approved work. When the owner approves something
and adds notes, apply the notes to that exact thing; if a note seems to need a new approach, ask first
(review-and-correct.md).
