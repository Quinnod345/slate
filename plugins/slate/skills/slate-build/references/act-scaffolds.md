# Act scaffolds: from placeholder to finished act

## The files

| File | What it holds |
|---|---|
| `scenes/act<N>/index.tsx` | the act: its default export is a component that receives `{sub, act, firstFrame}` |
| `scenes/act<N>/beats.ts` | React-free: every beat, computed at module level from the voice's words; motions and events registered here |
| `scenes/act<N>/events.ts` | optional: the act's events, when you keep them apart from the beats |
| `scenes/act<N>/NOTES.md` | the builder's notes (below) |
| `scenes/act<N>/*.tsx` | scene files per shot or per world, helpers |
| `scenes/contracts.tsx` | the named rest states acts meet on (shared, read-only to act builders once written) |
| `public/` | footage and captures scenes load with `staticFile()`, linked into the bundle, never copied |
| `.slate/`, `tsconfig.json` | generated by the engine; never edit |

The engine reads an act's modules in order (`events.*`, then `beats.*`, then `index.*`) for three exports: `events` (a
list, or a function returning one; `defineEvent` registrations count too), `silent` (a string saying why the act has no
beats) and `contracts` (`{in, out}`: the rest states its first and last frames match).

## Start with the placeholder

Until an act's scene exists, it renders as the kit's `PlaceholderAct`: its shot ids, on-screen text and voice, in the
brand's look, inside its `ActRoot`. The whole film plays from day one, and every act can be reviewed against the voice
before it's built.

**First working version of every shot, fast.** Block out every shot of the act roughly (the right objects, landing on
the right words) before refining any one of them. A session can end without warning; an act with every shot roughed
in is worth more than one perfect shot and nothing else.

## Beats at module level

```ts
// scenes/act2/beats.ts: React-free, so the engine can load it in Node
import {word, landOn, roleEase, defineMotion, defineEvent} from '@slate/kit/core';

// When the voice says "report" in shot S03 (film seconds). Never throws: a miss is estimated and recorded.
export const REPORT = word('S03', 'report');

// The card rises and lands (90% of its travel) on the word, on the brand's entrance ease and base duration.
export const cardUp = defineMotion({
  id: 'card-up', shot: 'S03', prop: 'y', from: 40, to: 0, entrance: true,
  ...landOn(REPORT, 'base', roleEase('entrance')),
});

// Tell the sound what happened, and when.
defineEvent({shot: 'S03', id: 'card_lands', t: REPORT, kind: 'land', size: 'm', note: 'the report card lands on "report"'});
```

```tsx
// scenes/act2/index.tsx
import {ActRoot, Card, useFilmTime} from '@slate/kit';
import type {SceneProps} from '@film/data';
import {cardUp} from './beats';

function Scene() {
  const t = useFilmTime();
  return <Card style={{transform: `translateY(${cardUp.atTime(t)}px)`}}>…</Card>;
}

export default function Act2({sub}: SceneProps) {
  return (
    <ActRoot act={2} sub={sub}>
      <Scene />
    </ActRoot>
  );
}
```

- **Everything is a function of film time.** No state carried between frames, no timers, no randomness: the renderer
  draws each frame up to 16 times across the shutter, and every sample must agree.
- **Use the brand's names** (`roleEase('entrance')`, the duration tokens), never literal curves or seconds.
- **Gate each element's entrance on the first word it shows**, not a later one.
- **Numbers are spoken words**: `word('S05', '2026')` finds "twenty twenty-six"; `word('S05', '&', 2)` finds the second
  "and".
- For a word stressed on a later syllable, measure the stress onset and record the offset in the beats file.

## NOTES.md

Every act keeps one, current from the first hour:
- **Checklist**: each ask from the brief and the script, re-read against the brief's own words, with evidence.
- **Files**: what each file holds.
- **What each shot shows**: a paragraph per shot, keyed to its words.
- **Decisions**: every judgement call and why (a rule conflict resolved with the smallest judgement that honours both;
  a law ease used where the brief's note disagreed).
- **Restaged**: every departure from the script's picture notes (the words and beats never change).
- **Contracts**: which rest states the act meets, and the proof (bit-identical boundary frames).
- **Character moves and score cues** for the sound pass (where the score drops, where one sound plays alone).
- **Truth pass**: every product element checked against the truth pack; omissions recorded.
- **Open, or couldn't do**: kit requests, gaps, anything left.
- **Log**: superseded cuts stay recorded, never silently erased.

Record deviations on surfaces outside your act instead of fixing them; facts several acts show (a tally, a standing)
come from one shared source, and a change to a shared surface goes to every act that shows it.

## Before calling it finished

Re-read the brief's original words against the act's checklist. Then hand in (hand-in.md).
