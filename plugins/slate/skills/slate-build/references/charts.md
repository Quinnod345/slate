# Data on screen: charts

Charts in a film are read once, in a few seconds, while the voice talks. They carry one idea each, and every number in
them is true (slate-story, truth-packs.md).

## Truth first

- Draw data graphics from the product's real distributions, ranges and clamps, never invented shapes.
- **Conceptual charts carry no numbers and no axis labels.**
- Illustrative graphics that aren't real data carry an illustration treatment and never show fabricated percentages.
- Future or illustrative points carry no numbers; only real sample readings are labelled.
- Show aggregated data the way the product aggregates it; never single out an individual.
- One company, one set of numbers: every chart of the sample reads from the same sample-data record.

## Drawing

- **Timelines of data are drawn to scale.** Label only the ends when the word budget is tight, and name partners in type
  (no partner logos).
- **Show a range as a solid value plus a lighter band.**
- **Hairline leaders can tie labels to the parts they describe.**
- **The accent colour keeps one meaning**: the line that matters is the accent; competing lines are ink.
- **Tabular figures** on every number that changes; count-ups count once, on the entrance ease, holding each figure
  three frames.
- The kit's charts (distributions, bars, lines, radar, rings, axes, markers) take the brand's tokens and the motion law.

## Motion

- Stagger along the data's direction: low to high, baseline to latest, the product's own order.
- A line draws on the entrance ease with a trim reveal; the value it lands on counts once.
- When an element lifts off a chart, its attached parts (area fill, head marker) go with it or fade gradually; never
  remove them all on one frame.
- Keep layouts stable when data changes: a column that reflows becomes a fast move.
- Show an analysis step as the signature line reading the data, so the pattern has a visible cause.

## Reading time

A number holds at least 2 s after its count lands. A chart with more than one idea needs more than one shot.
